---
title: "Why gold presets matter"
description: "QitOS v0.4 moves from one-off provider wiring to reusable family-level harness defaults."
---

QitOS started with a simple idea:

one kernel (the minimal async Agent loop), many agents.

v0.4 extends that idea to model families.

Instead of rewriting examples every time we try a new endpoint, we now resolve:

- a family preset (a reusable configuration bundle for a model family)
- a harness policy (the wiring layer that selects a model adapter and API identity)
- a transport adapter (the adapter that sends requests to and receives responses from a model API)
- native Tool-delivery and reasoning options for that API

Reproducible agent research is not only about trace files.

It is also about keeping the model-facing contract visible and stable.

The v0.4 flagship example can switch across Qwen, Kimi, MiniMax, `gpt-oss`, and Gemma 4 without changing the agent implementation itself.
