---
title: "Family presets"
description: "Resolve model-family adapters and request defaults without changing the Agent loop."
---

Family presets let one `Agent` composition switch model families while preserving the
same provider-neutral loop and Tool contracts.

The public surface is:

```python
from qitos.harness import (
    ContextPolicy,
    FamilyPreset,
    HarnessPolicy,
    ModelAdapter,
    ToolPolicy,
    build_harness_policy,
    build_model_for_preset,
    resolve_family_preset,
)
```

## What a preset controls

`build_model_for_preset(...)` selects a model adapter, applies model-family request and
reasoning defaults, and retains context-window hints as model metadata. The returned
object implements QitOS's normal Model contract and enters the same minimal Agent loop.

```python
from qitos.harness import build_model_for_preset

model = build_model_for_preset(
    model_name="Qwen/Qwen3-8B",
    family_id="qwen",
    api_key="...",
    base_url="https://example.invalid/v1",
)
```

You can also construct `OpenAICompatibleModel`, `OpenAIModel`, or `AnthropicModel`
directly when you do not need family defaults.

## Compatibility labels are not parsers

`FamilyPreset.default_protocol`, `fallback_protocols`, and the corresponding
`HarnessPolicy` fields are stable compatibility labels retained in harness metadata.
The minimal Agent loop does not load a text parser, inject an output protocol, or run a
fallback parser chain from those labels. Provider adapters deliver native typed
messages and Tool calls.

This distinction matters when reading older preset examples: a value such as
`json_decision_v1` does not add a second Decision/Action runtime.

## Override immutable defaults

```python
from dataclasses import replace
from qitos.harness import resolve_family_preset

qwen = resolve_family_preset("qwen")
custom = qwen.override(
    context_policy=replace(
        qwen.context_policy,
        context_window_hint=256_000,
    ),
)
```

`override()` returns a new preset. It does not mutate process-global state.

## Runtime boundary

- Presets choose model construction defaults; they do not replace the Agent loop.
- Tool exposure still comes from the turn's frozen `ToolRegistry` snapshot.
- Canonical protocol identity comes from the Model adapter's API capabilities.
- Harness metadata is diagnostic and never Session recovery truth.
