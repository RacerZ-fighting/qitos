---
title: "Trace artifacts"
description: "Inspect compatible QitOS trace directories with the read-only qita tools."
---

QitOS keeps the existing trace-directory format as a compatibility and inspection
surface. `qita` can read directories produced by earlier releases or by an explicit
application-side trace producer:

```text
<trace_logdir>/<run_id>/
  manifest.json
  events.jsonl
  steps.jsonl
```

<Warning>
The current `Agent` façade does not attach `TraceWriter` automatically. New Agent runs
can journal loop transactions through `SessionJournal`, but they do not produce this
three-file trace directory unless an application supplies a producer. Trace artifacts
are not Session recovery truth.
</Warning>

## What each file means

| File | Purpose |
| --- | --- |
| `manifest.json` | Run summary and producer-supplied reproducibility metadata |
| `events.jsonl` | Event stream recorded by the trace producer |
| `steps.jsonl` | Completed legacy step records |

For one trace directory, these files are the evidence that `qita` displays. They do
not replace the canonical Session Journal and cannot create an executable resume or
fork.

Older artifacts may contain fields such as `prompt_protocol`, `parser_name`,
`run_spec`, `experiment_spec`, or benchmark metadata. Those fields describe the
producer that wrote that artifact. They do not enable a parser, Decision/Action
lifecycle, benchmark runner, or Engine in the current Agent path.

## Inspect compatible artifacts

```bash
qita board --logdir ./runs
qita replay --run ./runs/<run_id>
qita export --run ./runs/<run_id> --html ./report.html
```

Use these commands to review, compare, and export existing evidence. Remote models and
external environments remain nondeterministic, so artifact replay is an inspection
operation rather than deterministic re-execution.

To continue a Run from a safe boundary, use the canonical Session Journal once the
authoritative Session/Harness migration exposes that workflow. Copying or editing a
trace directory never creates a resumable Run.
