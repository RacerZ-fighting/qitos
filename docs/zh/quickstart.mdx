本页会带你从零开始，在 2 分钟内完成一次模型驱动的智能体运行。

<Note>
如果你还没有远程模型服务和 API 密钥，建议先阅读 [前置准备](/zh/prerequisites)。其中说明了去哪里注册、如何创建 API 密钥，以及如何验证兼容 OpenAI 的服务商（provider）是否可用。
</Note>

## 前置条件

- Python 3.10 或更高版本
- `pip`
- 一个兼容 OpenAI 的 API 密钥

## 操作步骤

<Steps>
  <Step title="安装 QitOS">
    ```bash
    git clone https://github.com/Qitor/qitos.git
    cd qitos
    pip install ".[models]"
    ```

    可运行示例位于源码仓库中，不随 wheel 安装，因此快速开始从源码 checkout 起步。
  </Step>

  <Step title="设置服务商配置">
    ```bash
    export OPENAI_API_KEY="sk-..."
    export OPENAI_BASE_URL="https://api.openai.com/v1"
    export QITOS_MODEL="gpt-4o-mini"
    ```

    <Tip>
      任意兼容 OpenAI 的接口地址都可以使用。如果你不是直接使用 OpenAI，请将 `OPENAI_BASE_URL` 指向对应的服务商。
    </Tip>
  </Step>

  <Step title="运行最小智能体">
    ```bash
    python examples/quickstart/minimal_agent.py
    ```

    这个示例直接组合最小 agent loop：一个 `Agent` façade、一个 `OpenAICompatibleModel`，
    以及注册在 `ToolRegistry` 里的一个 `echo` 工具。`agent.prompt(...)` 驱动
    `Message -> Model -> ToolCall -> ToolResult` 循环并返回类型化 `AgentLoopResult`；
    示例会打印最后一条助手消息。
  </Step>

  <Step title="阅读组合方式">
    打开 [`examples/quickstart/minimal_agent.py`](https://github.com/Qitor/qitos/blob/main/examples/quickstart/minimal_agent.py)：

    ```python
    agent = Agent(
        model=model,
        tool_registry=ToolRegistry().register(echo),
        system_prompt="You are a minimal helpful agent. Answer concisely.",
        max_turns=4,
    )
    result = await agent.prompt("Call the echo tool once, then reply with what it returned.")
    ```

    模型、工具界面、提示词和轮次预算全部是显式的。子智能体、日志（journal）和监督（supervision）
    都基于同一个 façade 组合，参见 [kit 参考](/zh/reference/kit)。
  </Step>
</Steps>
