# 计算机操控与桌面环境

QitOS 把桌面/计算机操控作为一条官方主线。

核心组成：

- `DesktopEnv`
- `ComputerUseToolSet`
- `desktop_actions_json_v1` / `desktop_actions_xml_v1`
- qita 可视化回放

## 环境冒烟示例

最小的纯环境循环：

```bash
python examples/real/desktop_env_smoke.py
```

它不依赖模型，直接演练 `DesktopEnv` 与计算机操控工具集。
