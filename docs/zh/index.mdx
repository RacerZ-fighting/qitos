QitOS 是面向智能体（agent）研究者的类 PyTorch 风格框架。当前版本在 `Agent` façade 背后的最小异步 Agent loop 上原型化方法、观察长时运行轨迹（trajectory），并内置 `qita` 可观测性。

## 两种编写方式

QitOS 提供两种顶层的智能体编写方式：

- façade 优先：显式选择提示词、Provider 中立 Model 与冻结的工具面（tool surface）。
- 预设优先（preset-first）：从家族预设（family preset，预配置的模型家族默认值）和预设工具构建器出发，快速得到稳定基线（baseline）与多模型切换能力。

这两种方式都是一等公民。

## 快速启动

<Steps>
  <Step title="安装 QitOS">
    ```bash
    git clone https://github.com/Qitor/qitos.git
    cd qitos
    pip install ".[models]"
    ```
  </Step>
  <Step title="设置提供商配置">
    ```bash
    export OPENAI_API_KEY="sk-..."
    export OPENAI_BASE_URL="https://api.siliconflow.cn/v1/"
    export QITOS_MODEL="Qwen/Qwen3-8B"
    ```
  </Step>
  <Step title="运行最小智能体">
    ```bash
    python examples/quickstart/minimal_agent.py
    ```
    一个 `Agent` façade、一个模型、一个工具——示例会打印最终回复。
  </Step>
</Steps>
