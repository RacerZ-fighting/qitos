---
title: "用预设切换模型家族"
description: "让同一 Agent façade 使用不同模型家族的构造默认值。"
---

Family preset 在不改变最小 Agent loop 的前提下选择 Provider adapter 和模型请求
默认值。它不会安装 parser，也不会引入第二套执行运行时。

## Step 1 — 用 preset 构建模型

```python
from qitos.harness import build_model_for_preset

model = build_model_for_preset(
    family_id="qwen",
    model_name="Qwen/Qwen3-8B",
    api_key="...",
    base_url="https://api.siliconflow.cn/v1/",
)
```

返回对象实现普通 QitOS Model 契约。Preset 选择 adapter、请求与 reasoning 默认值、
Tool 交付策略和上下文窗口提示。Provider adapter 仍把类型化 assistant message 与
原生 Tool call 交给同一条 loop。

`default_protocol` 和 `fallback_protocols` 只是 `qitos_harness_metadata` 中保留的兼容
标签。当前 Agent loop 不会根据这些标签加载 parser 或注入输出协议。

## Step 2 — 运行同一份 Agent 组合

只改变模型构造：

```python
import asyncio

from qitos.core.agent import Agent
from qitos.harness import build_model_for_preset


async def main() -> None:
    configs = [
        ("qwen", "Qwen/Qwen3-8B", "https://api.siliconflow.cn/v1/"),
        ("kimi", "moonshot-v1-128k", "https://api.moonshot.ai/v1/"),
        ("deepseek", "deepseek-chat", "https://api.deepseek.com/v1/"),
    ]

    for family_id, model_name, base_url in configs:
        model = build_model_for_preset(
            family_id=family_id,
            model_name=model_name,
            api_key="...",
            base_url=base_url,
        )
        agent = Agent(model=model, max_turns=1)
        result = await agent.prompt("用一句话返回模型家族。")
        print(family_id, result.status.value)


asyncio.run(main())
```

真实代码应为每个 Provider 使用对应凭据，不要把 API key 写进源文件。

## Step 3 — 覆盖不可变默认值

```python
from dataclasses import replace
from qitos.harness import resolve_family_preset

qwen = resolve_family_preset("qwen")
custom_qwen = qwen.override(
    context_policy=replace(qwen.context_policy, context_window_hint=256_000),
    notes="Extended context variant for long-horizon tasks",
)
```

`override()` 返回新的 `FamilyPreset`，不会修改进程级全局状态。构造真实模型时，
把所需字段显式传给 `build_model_for_preset(...)`。

## Step 4 — 查看可用 preset

```bash
qit bench presets
```

该命令会输出 preset 标识、adapter 类型、Tool 交付策略、上下文提示与兼容标签。
这些标签是诊断 metadata，不是活跃的 fallback parser 链。

`recommended_*` 字段也只是建议。Agent façade 不会自动套用 step、token、retry 或
temperature 建议；应用自行选择 run budget 并显式传入模型请求选项。

## Step 5 — 比较实际模型边界

在 run 前检查 `model.capabilities` 与 `model.qitos_harness_metadata`：

```python
print(model.capabilities)
print(model.qitos_harness_metadata)
```

Capabilities 描述选中 adapter 已由测试证明的行为；harness metadata 记录 preset 的解析
方式。两者都不是 Session 恢复真源。

如果应用另外生成兼容 trace artifact，只读 `qita` 可以比较 producer 记录的模型
metadata。当前 Agent façade 不会自动生成这些 trace 目录。
