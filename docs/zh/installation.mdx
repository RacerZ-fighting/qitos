<Warning>
QitOS 当前处于 **Beta** 阶段。当前版本发布最小 agent loop 与 `Agent` façade。Trace/qita 行为和规范化示例会继续保留，但生产环境应固定版本，并在升级前检查 Changelog。
</Warning>

## 环境要求

QitOS 需要 **Python 3.10 及以上**。当前测试覆盖 Python 3.10、3.11 和 3.12。

<Note>
如果你还没有远程模型 API，可以先看 [前置准备](/zh/prerequisites)，其中整理了推荐平台、API 密钥获取方式和最小连通性验证。
</Note>

## 标准安装

从 PyPI 安装核心框架：

```bash
pip install qitos
```

核心安装包含：

- 最小 agent loop 与 `Agent` façade 运行时
- `qita` 可观测性工具
- `kit` 工具箱模块

它默认不包含 OpenAI 客户端。

<Tip>
如果你想马上运行最小编程智能体（coding agent）快速入门，直接安装 `pip install "qitos[models]"` 即可。
</Tip>

## 可选扩展组件（extras）

通过扩展组件按需加入模型支持、基准测试依赖，或一次性安装全部组件。

<CodeGroup>

```bash 模型支持
pip install "qitos[models]"
```

```bash 全部安装
pip install "qitos[all]"
```

</CodeGroup>

| 扩展组件 | 增加的内容 |
|---|---|
| `models` | `openai>=1.66.0`，用于 Chat Completions 与可选 Responses API 模型接口 |
| `all` | 以上全部 |

<Tip>
如果你刚开始接触 QitOS，最推荐 `pip install "qitos[models]"`。这足以跑通最小编程智能体快速入门和大部分示例。
</Tip>

## 从源码安装

克隆仓库后，以可编辑模式安装，并带上开发依赖：

```bash
git clone https://github.com/Qitor/qitos.git
cd qitos
pip install -e ".[dev,models]"
```

`dev` 扩展组件会安装 `pytest`、`black`、`flake8`、`mypy` 以及 QitOS 团队使用的打包工具。

## 验证安装

确认包是否安装成功，并查看版本：

```bash
python -c "import qitos; print(qitos.__version__)"
```

你应该能看到：

```
0.3.0
```

也可以顺便验证两个命令行工具（CLI）是否已进入 PATH：

```bash
qit --help
qita --help
```
