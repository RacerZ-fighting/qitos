---
title: "Family Presets"
description: "在不改变 Agent loop 的前提下解析模型家族 adapter 与请求默认值。"
---

Family preset 让同一套 `Agent` 组合切换不同模型家族，同时保持 Provider 中立的 loop 与
Tool 契约不变。

公共入口包括：

```python
from qitos.harness import (
    ContextPolicy,
    FamilyPreset,
    HarnessPolicy,
    ModelAdapter,
    ToolPolicy,
    build_harness_policy,
    build_model_for_preset,
    resolve_family_preset,
)
```

## 预设实际控制什么

`build_model_for_preset(...)` 会选择 model adapter，应用模型家族的请求与 reasoning
默认值，并把上下文窗口提示保留为模型元信息。返回对象实现普通 QitOS Model 契约，进入
同一条最小 Agent loop。

```python
from qitos.harness import build_model_for_preset

model = build_model_for_preset(
    model_name="Qwen/Qwen3-8B",
    family_id="qwen",
    api_key="...",
    base_url="https://example.invalid/v1",
)
```

如果不需要家族默认值，也可以直接构造 `OpenAICompatibleModel`、`OpenAIModel` 或
`AnthropicModel`。

## 兼容标签不是 parser

`FamilyPreset.default_protocol`、`fallback_protocols` 与对应的 `HarnessPolicy` 字段是
保留在 harness metadata 中的稳定兼容标签。最小 Agent loop 不会根据这些标签加载文本
parser、注入输出协议或运行 fallback parser 链。Provider adapter 直接交付类型化消息与
Tool call。

因此，旧示例中的 `json_decision_v1` 不会引入第二套 Decision/Action runtime。

## 覆盖不可变默认值

```python
from dataclasses import replace
from qitos.harness import resolve_family_preset

qwen = resolve_family_preset("qwen")
custom = qwen.override(
    context_policy=replace(
        qwen.context_policy,
        context_window_hint=256_000,
    ),
)
```

`override()` 返回新 preset，不修改进程级全局状态。

## 运行时边界

- Preset 只选择模型构造默认值，不替换 Agent loop。
- Tool exposure 仍来自当前 turn 的冻结 `ToolRegistry` 快照。
- Canonical protocol identity 来自 Model adapter 的 API capabilities。
- Harness metadata 只用于诊断，不是 Session recovery 真源。
