QitOS 提供两个顶层命令行工具：

- `qita`：追踪记录检查与回放
- `qit`：基准测试与开发者工作流入口

## qita

当你要检查已有追踪记录时，使用 `qita`。

### `qita board`

```bash
qita board --logdir ./runs
```

打开多运行面板，支持：

- 运行列表与过滤
- 对比选择
- 进入运行详情
- 回放
- 原始或 HTML 导出

### `qita replay`

```bash
qita replay --run ./runs/<run_id>
```

以时间轴方式打开一个运行。

### `qita export`

```bash
qita export --run ./runs/<run_id> --html ./report.html
```

导出独立 HTML 产物。

## qit bench

`qit bench` 处理统一的基准测试结果文件与运行产物。

### `qit bench eval`

```bash
qit bench eval --input ./results/tau.jsonl --json
```

聚合统一基准测试结果。

### `qit bench replay`

```bash
qit bench replay --run ./runs/<run_id>
```

把基准测试运行直接桥接到 qita 回放。

### `qit bench export`

```bash
qit bench export --run ./runs/<run_id> --html ./report.html
```

把基准测试运行导出成独立 HTML。

## 推荐流程

第一次跑通时，推荐：

1. `export OPENAI_API_KEY=...`
2. `python examples/quickstart/minimal_agent.py`

处理外部产出的基准测试结果文件时，推荐：

1. `qit bench eval`
2. `qita board`
3. `qit bench replay`
4. `qit bench export`

如果你还想理解这条路径背后的设计，请继续阅读 [追踪](/zh/concepts/tracing)。
