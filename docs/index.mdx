QitOS is a PyTorch-style framework for agent researchers. Current releases let you prototype methods, run benchmarks, and inspect long-horizon trajectories through the shipped `AgentModule + Engine` runtime, with built-in observability via `qita` (the trace viewer that ships with QitOS). The accepted next architecture replaces that runtime in place with a Model, minimal async Agent loop, and durable Session/Harness; the guides below continue to document the installed release until migration completes.

## Two authoring paths

QitOS offers two top-level ways to build agents:

- **Research-first**: handwrite the prompt, parser, protocol (the output format contract between model and parser), transport (the client that talks to the model API), and tool surface so you can study and optimize the kernel directly.
- **Preset-first**: start from family presets (pre-configured model-family defaults) and preset tool builders when you want a fast baseline or quick multi-family switching.

Both paths are first-class citizens in the framework.

## Get up and running

<Steps>
  <Step title="Install QitOS">
    ```bash
    pip install "qitos[models]"
    ```
  </Step>
  <Step title="Set your provider config">
    ```bash
    export OPENAI_API_KEY="sk-..."
    export OPENAI_BASE_URL="https://api.siliconflow.cn/v1/"
    export QITOS_MODEL="Qwen/Qwen3-8B"
    ```
  </Step>
  <Step title="Run the minimal agent">
    ```bash
    python examples/quickstart/minimal_agent.py
    ```
    One `Agent` façade, one model, one Tool — the example prints the final reply.
  </Step>
</Steps>
