---
title: "Observability"
description: "Inspect, replay, and export compatible trace artifacts with qita."
---

`qita` is a read-only viewer for QitOS trace artifacts. It discovers existing run
directories, renders their recorded trajectory, replays events, and exports standalone
HTML. It never becomes the canonical Session or journal owner.

<Warning>
The minimal `Agent` loop does not yet attach `TraceWriter` automatically. Do not expect
`agent.prompt(...)` to create `./runs/<run_id>/`. Automatic projection from the new
loop/façade event stream is tracked in the Session/Harness migration.
</Warning>

## Accepted input

Point qita at a directory containing compatible trace run directories. Historical
artifacts normally contain `manifest.json`, `events.jsonl`, and `steps.jsonl`; qita
validates what it can read and treats missing provenance as incomplete rather than
inventing it.

The Agent loop's append-only Session journal is a different format and remains the
canonical source for model transactions, Tool terminals, committed turns, and run
terminals. qita does not convert or repair that journal during reads.

## Board

```bash
qita board --logdir ./runs
```

The board listens on `http://127.0.0.1:8765` by default.

| Flag | Default | Description |
|---|---|---|
| `--logdir` | `./runs` | Root containing compatible trace directories |
| `--host` | `127.0.0.1` | Bind address |
| `--port` | `8765` | Bind port |

```bash
qita board --logdir ./runs --host 0.0.0.0 --port 9000
```

The board provides search, status filters, sorting, run metadata, recorded steps, and
paired Tool-call/result evidence when the source artifact contains it.

## Replay

```bash
qita replay --run ./runs/example-run
```

Replay walks the events recorded in one compatible run directory. It is a presentation
of persisted evidence, not a resume operation and never executes a model or Tool.

## Export

```bash
qita export --run ./runs/example-run --html out.html
```

The exported HTML embeds the readable run data, CSS, and JavaScript. Review the source
artifact for secrets before sharing either the artifact or the export.

## Current boundary

- Session journals are canonical runtime state.
- qita trace artifacts are observational projections.
- Provider continuation and qita indexes are not recovery truth.
- Trace production for the minimal loop remains pending; qita viewing existing
  compatible artifacts is available now.
