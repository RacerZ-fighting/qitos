---
title: "Multimodal messages"
description: "Send typed text and image content through the current Agent façade."
---

The minimal Agent loop keeps multimodal input in the canonical `UserMessage` contract.
It does not need a vision-only runtime, prompt protocol, parser, or `Decision` type.

## Construct a typed image message

```python
from qitos.core.message import ImageContent, TextContent, UserMessage

message = UserMessage(
    content=(
        TextContent(text="Inspect this screenshot."),
        ImageContent(
            source={
                "type": "image_file",
                "path": "screen.png",
                "detail": "high",
            }
        ),
    )
)

result = await agent.prompt(message)
```

`ImageContent.source` retains the Provider-neutral wire mapping in the durable message
codec. OpenAI-compatible and Anthropic adapters project supported image blocks to their
own API shape. Check `model.capabilities.multimodal_input` before relying on image
delivery.

The same message contract can carry an `image_url` or adapter-supported base64 source.
Invalid durable message shapes fail closed during decode.

## Environment observations are application projections

`ScreenshotEnv` and `DesktopEnv` expose structured observations with screenshots and
optional DOM, OCR, accessibility, or terminal context. The Agent loop does not poll an
environment automatically. Applications decide when to observe and which bounded facts
to project into the next `UserMessage`.

This keeps three responsibilities separate:

- the environment owns observation and controller operations;
- the Model adapter owns multimodal wire projection;
- the Agent loop owns typed messages, Tool calls, and Tool results.

## Current trace boundary

`qita` can display visual fields in compatible trace artifacts. Those files may include
legacy step, parser, or grounding fields written by their producer. New Agent runs do
not emit that trace format automatically, and visual trace assets are not Session
recovery truth.

For the environment-only source-checkout smoke path, run:

```bash
python examples/real/desktop_env_smoke.py
```
